# Portfolio Website - Aditya Kamble

A modern, responsive portfolio website showcasing skills, experience, and projects as a Full Stack Developer.

## Features

- **Modern Design**: Beautiful gradient effects, smooth animations, and a clean UI
- **Responsive Layout**: Works seamlessly on desktop, tablet, and mobile devices
- **Interactive Elements**: 
  - Animated typing text effect
  - Smooth scrolling navigation
  - Skill progress bars with animations
  - Hover effects on cards and buttons
- **Sections**:
  - Hero section with animated background
  - About section with personal information
  - Skills section with progress bars
  - Experience & Education timeline
  - Projects showcase
  - Contact form

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- JavaScript (Vanilla JS)
- Font Awesome icons

## Getting Started

1. Simply open `index.html` in your web browser
2. No build process or installation required!

## Customization

You can easily customize:
- Colors: Update CSS variables in `styles.css` (`:root` section)
- Content: Edit the HTML content in `index.html`
- Animations: Modify JavaScript animations in `script.js`

Works on all modern browsers including:
